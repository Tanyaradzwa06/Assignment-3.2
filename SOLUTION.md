# Assignment 3.2 — Images in HTML

## 1. Aim

The aim of this assignment is to learn how to add images to a portfolio webpage using HTML and display them correctly in a web browser.

## 2. Introduction

Images are an important part of a website because they make webpages attractive, informative, and engaging. HTML provides the `<img>` tag to insert images into a webpage. Images can be used to display personal photographs, project screenshots, logos, and other visual content on a portfolio website.

## 3. Theory

The `<img>` tag is used to embed an image in an HTML document. It is an empty tag, which means it does not require a closing tag.

The following attributes are commonly used with the `<img>` tag:

- src: Specifies the path or URL of the image file.
- alt: Provides alternative text that describes the image. It is useful for screen readers and is displayed when an image cannot load.
- width: Specifies the width of the image.
- height: Specifies the height of the image.



## 4. Importance of the Alt Attribute

The `alt` attribute improves the accessibility of a webpage by providing a text description of each image. It helps visually impaired users understand image content through screen readers. It also provides useful information if an image fails to load.

Each image should have meaningful and descriptive alternative text rather than a generic description such as "image" or "photo."

## 5. Image Paths

An image path tells the browser where an image file is located. If the images are stored in a folder named `images` within the project directory, the path must correctly refer to that folder and the corresponding filename.

Correct image paths are essential because an incorrect path may prevent the browser from displaying the image. Filenames, file extensions, and folder names should be checked carefully.

## 6. Width and Height Attributes

The `width` and `height` attributes define the displayed dimensions of an image. They help maintain a consistent layout and prevent images from appearing too large or too small. The dimensions should be selected according to the design of the portfolio webpage while maintaining the image's original aspect ratio.


## 7. Advantages of Using Images in HTML

1. Images make webpages more attractive and visually appealing.
2. They help present information in a clear and effective way.
3. They improve the overall design of a portfolio website.
4. The `alt` attribute improves accessibility.
5. Properly organized image files make project maintenance easier.

## 8. Conclusion

In this assignment, I learned how to use the HTML `<img>` tag to add images to a portfolio webpage. I understood the importance of the `src`, `alt`, `width`, and `height` attributes, along with the correct use of image paths. I also learned how to organize images in a separate folder and verify that they display correctly in a browser. This assignment helped me understand how to use images effectively and improve the accessibility and appearance of a website.
